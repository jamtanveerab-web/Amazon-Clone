# Amazon Clone

## Description
A front-end clone of Amazon's homepage created using only HTML and CSS. This project demonstrates my ability to replicate modern e-commerce website designs with responsive layout.

## Features
- Responsive navigation bar
- Product cards with images and pricing
- Footer section
- Hover effects on buttons and links
- Mobile-friendly design

## Technologies Used
- HTML5
- CSS3 (Flexbox & Grid)

## What I Learned
- Structuring a real-world e-commerce layout
- Using CSS Flexbox and Grid for responsive design
- Organizing CSS files for maintainability
