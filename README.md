# 🛒 Amazon Clone

A front-end clone of Amazon's homepage built with pure HTML and CSS. This project demonstrates my ability to replicate modern e-commerce website designs with responsive layout and attention to detail.

## 📸 Preview

(Add a screenshot here in the future)

## ✨ Features

- Responsive navigation bar with logo, search box, and cart icon
- Hero/Banner section
- Product cards with images, titles, pricing, and ratings
- Sidebar categories menu
- Footer section with multiple columns
- Hover effects on buttons, links, and product cards
- Mobile-friendly responsive design
- Clean and organized folder structure

## 🛠️ Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Flexbox, Grid, hover effects, media queries
